## Ответы на вопросы

### 1. В чём разница между полем класса и обычной переменной в функции?

Поле класса является частью объекта и хранит данные, связанные с этим объектом. Обычная переменная в функции существует только во время выполнения этой функции и доступна только внутри неё.

### 2. Что такое конструктор и зачем он нужен?

Конструктор — специальный метод класса, который вызывается при создании объекта. Он используется для задания начальных значений его полей и первоначальной настройки объекта.

### 3. Зачем нужен `@override` перед `toString()`? Что будет если его убрать?

`@override` указывает, что метод переопределяет метод родительского класса. `toString()` существует у всех объектов Dart, поэтому его можно переопределить для вывода информации об объекте в удобном формате.

Если убрать `@override`, метод всё равно будет работать, но компилятор не будет дополнительно проверять, действительно ли переопределяется существующий метод.

### 4. Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?

Обычное поле относится к конкретному объекту, поэтому каждый объект имеет свою копию этого поля.

Статическое поле `static int _counter` относится ко всему классу, а не к отдельному объекту. Поэтому существует **одна общая копия** этого поля для всего класса.

### 5. Что означает нижнее подчёркивание в `_counter`?

Нижнее подчёркивание в начале имени обозначает приватный член. Поле `_counter` доступно только внутри библиотеки, в которой оно объявлено.
