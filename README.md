## Ответы на вопросы

### 1. В чём разница между полем класса и обычной переменной в функции?

**Поле класса** хранит данные, которые относятся к объекту или самому классу, и доступно в его методах. Оно существует столько, сколько существует соответствующий объект (для обычного поля).

**Обычная переменная в функции** создаётся внутри функции и используется только во время её выполнения. За пределами функции она недоступна.

### 2. Что такое конструктор и зачем он нужен?

**Конструктор** — специальный метод класса, который вызывается при создании объекта. Он нужен для первоначальной настройки и инициализации его полей.

Например:

```dart
class Todo {
  String title;

  Todo(this.title);
}
```

При создании `Todo('Изучить Dart')` значение передаётся в поле `title`.

### 3. Зачем нужен `@override` перед `toString()`? Что будет, если его убрать?

`@override` показывает, что метод переопределяет метод, который уже существует в родительском классе.

У всех объектов Dart есть метод `toString()`, поэтому его можно переопределить, чтобы задать собственное строковое представление объекта.

Если убрать `@override`, переопределение метода **всё равно будет работать**, но компилятор не сможет дополнительно проверить, действительно ли метод переопределяет существующий метод родительского класса.

### 4. Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?

Обычное поле принадлежит конкретному объекту класса. Поэтому у каждого созданного объекта будет **своя копия** этого поля.

Статическое поле `static` принадлежит самому классу, а не отдельным объектам. Поэтому независимо от количества созданных объектов существует **одна общая копия** этого поля для всего класса.

### 5. Что означает нижнее подчёркивание в `_counter`?

В Dart нижнее подчёркивание в начале имени (`_counter`) обозначает, что член является **приватным**.

Такое поле доступно только внутри той библиотеки Dart, в которой оно объявлено. Из другого файла напрямую обратиться к `_counter` нельзя.
